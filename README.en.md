# ❤️ Love Score — a SillyTavern extension

Tracks the love score between the player and the character right inside the chat. A heart widget floats over the interface and fills up as the relationship grows. All rules, behavior ranges and romantic events are generated by AI — all you have to do is press a button.

---

## 📦 Installation

1. Open SillyTavern → **Extensions** → **Install extension**
2. Paste the repository link:
   ```
   https://github.com/KiskaSora/love-score.git
   ```
3. Click **Install** and reload the page
4. The 🪄 (**Magic Wand**) icon above the input field → **❤️ Love Score** opens the control window

---

## 🚀 Quick start

1. Open a chat with a character
2. Click the 🪄 (**Magic Wand**) icon above the input field and pick **❤️ Love Score** — the control window opens
3. In the **AI** tab, set the Endpoint and API Key of any OpenAI-compatible API
4. Click **Generate** — the extension reads the character card and automatically fills in all the rules, ranges and events
5. Start chatting — the widget updates itself after every bot reply

> **Where is the panel?** Since version 1.7.0 all controls moved from the settings sidebar into the **wand menu** (🪄 above the input field) and open in a separate responsive window — handy on both desktop and phone. The heart widget stays floating over the chat. A **double tap/click** on the heart opens the window too.

---

## 🗂 The control window

At the top there's a live header with the score, a trend arrow and a mini-chart (visible from any tab). Below it are the horizontal tabs:

| Tab | What's inside |
|---|---|
| **Overview** | Current score, relationship type, what the character is playing right now, change history, the dynamics chart, scars |
| **Modes** | Game modes (SlowBurn, Hardcore, Cold start, Scars, Streak, Momentum) + the "Display & injection" block: heart size and style, injection tone, hidden rules, reason in the log |
| **Rules** | Score-change rules, behavior by ranges, romantic events, routes |
| **AI** | Rule generation, chat analysis, auto-regeneration, data sources (card/lorebook), generation language |
| **Surroundings** | NPC mode: track several characters at once, rivals for attention |
| **Presets** | Save/load rule sets, import/export via JSON |
| **Debug** | The full prompt injection, current state, AI tags |

## ✨ Features

### ♥ Heart widget
A heart floating over the interface. It fills up as the score grows, changes color depending on the relationship type, and flips over when the score goes negative. Draggable and resizable. Two styles: **fill** (SVG) and **blur**. A **single tap** shows a tooltip (relationship type and current behavior); a **double tap/click** opens the control window (can be disabled in the **Modes** tab).

### 🌐 Bilingual interface
The interface adapts to SillyTavern's language automatically: Russian by default, English whenever the tavern is set to any non-Russian language (en, ja, de, fr…). Nothing to configure separately — the extension reads the tavern's language setting on its own.

### 📊 Per-chat data
Every chat keeps its own score, rules and history independently of the others.

### ⚖️ Score-change rules
Define what makes the score go up and down — with arbitrary delta values and a text description of the condition. These rules are injected into the system prompt and steer the AI's behavior.

### 🎭 Behavior ranges
Describe how the character behaves at different score values. The active range is automatically added to the prompt, making the bot play its role more accurately.

### 💫 Romantic events
Set thresholds at which the character should initiate a special moment on its own. The extension marks them done when the bot includes the right tag in its reply. The threshold can be stretched with the **"Generate events … up to N"** button — even to very large values, if you want the bot to keep surprising you for a long time.

### 🤖 AI generation
Connect any OpenAI-compatible API and generate rules, ranges and events with one click — tailored to the specific character. Supports chat history and a generation-language choice (RU/EN) for more accurate results.

Configurable generation sections:
- Score-change rules
- Positive ranges (0 … max)
- Negative ranges (−100 … −1)
- Romantic events
- Suggested maximum score

### 🔄 Auto-regeneration
Every N messages the AI automatically rebuilds all the rules based on the current chat history — keeping them alive and accurate throughout the whole story.

### 🔍 Chat analysis
The AI reads the history and the character card and suggests an up-to-date relationship score with an explanation.

### 👥 Surroundings mode (NPC)
Track relationships with several characters at once. Add NPCs manually, from a lorebook, or via auto-scanning the chat. Each NPC has its own score, relationship type and progress bar.

### 🌍 SlowBurn
A slowed-down progression mode: score change is capped at ±2 per reply (unless an exact rule fires). Creates a feeling of gradual, realistic relationship development. Toggled in the **Modes** tab.

### ☠️ Hardcore
A mode where love is hard to earn and easy to lose. Overrides SlowBurn when enabled.

- **Gain cap** — at most +0.5 per reply ("effort"). The AI awards points only for real effort: care, sacrifice, a kept promise, vulnerability. Empty small talk and rote compliments give 0.
- **Stronger penalties** — mistakes, rudeness and betrayal hit with a multiplier (×2 by default).
- **Decay** — if there's no progress for several turns, the score "cools down" toward zero on its own. Warmth must be maintained constantly, not banked and forgotten.
- **Breakthrough** — for a rare, unforgettable moment the AI can grant a big jump via the `<!-- [HC_BREAKTHROUGH:N] -->` tag. After it fires it goes on cooldown to stay rare.
- **Cold heart** — the widget glows cold steel at low scores and only warms up as the relationship grows.

All parameters (cap size, penalty multiplier, decay step and interval, breakthrough cooldown) are set in the mode card in the **Modes** tab.

### ❄️ Cold start
New chats begin not at 0 but in the negative (−30 by default) — a "wall of distrust" the player has to climb out of. Especially strong paired with Hardcore.

- **Start in the negative** — the character is a wary stranger at first, not a blank slate.
- **Smart distinction** — until the score reaches zero for the first time, the AI plays exactly cold distance and skepticism toward a stranger, *not betrayal-driven hatred*. Once trust is established (score ≥ 0), this distinction is dropped forever: any future dip into the negative is read as a damaged relationship.
- **Applies to new chats** (those without existing Love Score data). The toggle doesn't touch the current chat — there's a separate "Apply to this chat" button for that.
- **Generation hint** — when the mode is on, the AI describes the upper negative ranges as wariness rather than hostility.

The starting value is set in the mode card in the **Modes** tab.

### 🩹 Scars
Big hurts leave a mark. When the score drops sharply (by −10 or more at once, by default), the system records a scar — a text memory of the wound that is injected into the prompt and makes the character remember the offense even after reconciliation.

- **Auto-scar** on a big drop (threshold configurable).
- **The [SCAR:…] tag** — the AI can name the wound in its own words the moment something deeply hurts the character. If the AI marked the wound itself, the auto-scar isn't duplicated.
- **Healing** — a scar closes when the score rises above the point of offense by a set margin (+30 by default). A margin of `0` = a scar forever. Forgiveness requires real recovery, not just a return to the previous level.
- **Manual control** — scars can be added, healed and removed manually in the **Overview** tab. Healed scars stay in the history but no longer affect behavior.

The threshold and healing margin are set in the mode card in the **Modes** tab.

### 🔥 Streak
Several positive replies in a row boost the next gain. In normal mode the multiplier is ×1.5 (configurable); in hardcore it raises the cap once from +0.5 to +1. A triggered streak is "spent" and starts building up again. A negative breaks the streak. Explicit rules and breakthroughs are left untouched by the streak.

### 🌊 Event momentum
After a big score shift (±8 at once, by default) the character stays "under the impression" for several turns — a note is injected into the prompt so the experience echoes in the roleplay. It doesn't affect the score, only behavior. Fades out gradually.

### 🎭 Hidden rules & injection tone
Control over **how** the system talks to the bot (the **Modes** tab, "Display & injection" block):
- **Hidden rules** — don't show the bot the score table, deltas and thresholds, only the current behavior and score. Stronger immersion, especially with hardcore ("you don't know what you're being scored for"). Machine tags are preserved, so the mechanics keep working.
- **Injection tone** — three delivery styles: *strict rules* (the old way), *hints* (soft wording), *inner monologue* (instructions in the character's first person).

### 💬 Reason in the log
Turn on the toggle in the **Modes** tab and the AI will attach a short reason to every score change. The history in the **Overview** tab then shows **what exactly** the character liked or disliked, not just "±N points".

### ↕️ Trend arrow & history chart
- **The arrow** by the heart shows the direction of the latest changes (▲ ▼ ▭).
- **The chart** in the **Overview** tab (and the mini version in the window header) draws the score dynamics over the last turns. Both are reconstructed from the change history — no separate data required. Toggled in the **Modes** tab.

### ⚖️ Conditional rules
A score-change rule can fire only under set conditions:
- **Score range** — e.g. "+3 for a confession, but only if the score ≥ 60".
- **Route binding** — the rule is active only within its development branch (see below).
- Rules without conditions stay universal and work everywhere, as before.

Conditions are edited right in the rule card in the **Rules** tab. Rules that don't fit the current score aren't injected to the bot.

### 🛤 Routes (development branches)
> Replaced the old "arcs". Previously the story was split into chapters by **score range** — now into branches by **relationship type**.

Each route is a development branch for a specific relationship type (love, obsession, friendship, cooling off…). The branch whose type matches the current relationship type automatically becomes active: its name and mood description are injected into the prompt and set the tone of the scene. Each branch can have its own set of conditional rules that work only inside it.

- **Generate routes** — the AI creates one branch per relationship type that fits the character with a single click (source — from the **AI** tab).
- Conditional rules attach to routes (the "route" field in the rule card).

Configured in the **Rules** tab.

### ⚔️ Rival
Any NPC in **Surroundings mode** can be flagged as a **⚔ rival for attention**. Then its growth presses on your main score: for each +1 the rival gains, a set **pressure** is subtracted from your score (−0.5 by default, configured per NPC). The rival falling gives no bonus — creating a love triangle with a real cost of inaction.

The AI updates the rival's score with the same tag as a regular NPC: `<!-- [NPC_SCORE:EnName:X] -->`. Several rivals can press at once. Flagged right in the NPC card in the **Surroundings** tab.

### 💾 Presets
Save and load rule sets. A snapshot is taken automatically before each generation — easy to roll back. Import and export via JSON.

### 🔗 Lorebook as a data source
Besides the character card, the AI can use lorebook entries — pick the entries you need right in the interface.

### 🐛 Debug
A tab with the full prompt injection, current state, NPCs and AI tags — handy for diagnostics.

## 🤖 How the bot reads the score

The extension adds a hidden system block to every message. The bot includes special tags at the end of each reply:

```
<!-- [LOVE_SCORE:47] -->
```

When a romantic event is fulfilled:
```
<!-- [MILESTONE:30] -->
```

When the relationship type is determined:
```
<!-- [RELATION_TYPE:romance] -->
```

In surroundings mode — for an NPC:
```
<!-- [NPC_SCORE:Alice:23] -->
<!-- [NPC_TYPE:Alice:friendship] -->
```

Depending on the enabled modes, the bot may also use:
```
<!-- [HC_BREAKTHROUGH:5] -->     a rare big jump in hardcore (bypasses the cap)
<!-- [SCAR:he lied about the money] -->   mark a deep hurt (a scar)
```

A rival's score is updated with the regular NPC tag — `<!-- [NPC_SCORE:EnName:X] -->`; if the NPC is flagged as a rival, its growth automatically presses on the main score.

The extension detects these tags automatically and updates the widget.
